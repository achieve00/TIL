## 2. 에이전트 AI
- function calling과 tool call의 차이점
    - function calling: 주어진 함수의 매개변수 형식을 정의 → 해당 구조에 맞춰 함수 호출하여 결과 사용
    - tool call: LLM 기반의 프레임워크에서 텍스트로 요청을 보내 함수를 외부 함수나 도구로 실행 → 해당 결과 처리
- API를 통해 질문하고 답변 받기
    ```
    response = client.chat.completions.create(
    model = 'gpt-4o',
    temperature = 0.1, # 무작위성 조절
    messages = [
        {"role": "system", "content": "You are a helpful assistant."}, # GPT의 역할 설정
        {"role": "user", "content": "2022년 월드컵 우승 팀은 어디야?"}, # LLM과 대화를 나누는 사용자
        # assistant - LLM이 제공하는 답변을 의미
    ]
    )
    ```
- 퓨샷 프롬프팅 적용 방식
    - role 중 **user, assistant**를 이용하여 예시를 몇 가지 제공하고, 다시 user를 이용해 질문
- 멀티턴 대화 방식
    - 함수 형태로 응답 생성을 만듦
    - 초기 시스템 메시지를 설정
    - user_input을 받아서 응답을 messages에 저장하면서 대화 기록을 저장
- streamlit
    - st.session_state: 사용자의 세션 상태를 관리
    - state.messages: streamlit의 채팅 인터페이스에서 메시지를 출력하는 용도
    - st.chat_input(): 사용자의 입력을 받음
    ```
    # 질문 내용을 session_state.messages에 딕셔너리 형태로 추가하고 화면에 사용자 입력 내용 출력
    st.session_state.messages.append({"role": "user", "content": prompt}) 
    st.chat_message("user").write(prompt) 

    # AI 답변 내용을 session_state.messages에 딕셔너리 형태로 추가하고 화면에 답변 출력
    response = client.chat.completions.create(model="gpt-4o", messages=st.session_state.messages) 
    msg = response.choices[0].message.content
    st.session_state.messages.append({"role": "assistant", "content": msg}) 
    st.chat_message("assistant").write(msg)
    ```
