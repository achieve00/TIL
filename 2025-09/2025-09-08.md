## 1. 코딩테스트
### 이코테
- 알고리즘: DFS/BFS
#### 스택
- 선입후출 구조
- 파이썬에서 스택을 이용할 때에는 별도의 라이브러리 사용 필요 x
- 재귀함수의 수행은 스택과 같은 형식으로 실행 -> 구현 시 재귀함수를 사용하기도 함

#### 큐
- 선입선출 구조
- deque 라이브러리 사용해서 구현
`from collections import deque`

#### DFS
- 깊이 우선 탐색
    + 탐색 시작 노드를 스택에 삽입하고 방문 처리를 함
    + 스택의 최상단 노드에 방문하지 않은 인접 노드가 있으면 그 인접 노드를 스택에 넣고, 방문처리. 방문하지 않은 인접 노드가 없다면 스택에서 최상단 노드를 꺼냄
    + 2번과정을 수행할 수 없을때까지 반복

```
def dfs(graph, v, visited):
    # 방문 처리
    visited[v] = True
    
    # 재귀적으로 방문
    for i in graph[v]:
        if not visited[i]:
            dfs(graph, i, visited)

```

#### BFS
- 너비 우선 탐색
- 가까운 노드부터 방문
    + 탐색 시작 노드를 큐에 삽입하고 방문처리
    + 큐에서 노드를 꺼내 해당 노드의 인접 노드 중에서 방문하지 않은 노드를 모두 큐에 삽입하고 방문처리
    + 2 과정을 더이상 수행할 수 없을 때까지 반복

```
from collections import deque

def bfs(graph, start, visited):
    queue = deque([start])

    visited[start] = True

    # 큐가 빌 때까지 반복
    while queue:
        v = queue.popleft()

        for i in graph[v]:
            if not visited[i]:
                queue.append(i)
                visited[i] = True


```
